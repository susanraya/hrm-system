# HRM SYSTEM

Human resource management system

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a Django REST Framework service. No architecture had been
  approved when this repository was created, so it starts with its health check
  and nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
python manage.py migrate --run-syncdb
python manage.py runserver
pytest
ruff check .
ruff format .
```
